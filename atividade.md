Unit Authenticator
Em um mundo cada vez mais digitalizado, a segurança da informação
tornou-se um dos maiores desafios para indivíduos e organizações. O aumento de
ataques cibernéticos, fraudes e acessos não autorizados fez com que sistemas de
autenticação se tornassem indispensáveis em praticamente todos os serviços
online. Desde redes sociais e sistemas bancários até aplicações corporativas e
governamentais, a autenticação é a primeira linha de defesa contra acessos
indevidos.
A autenticação é o processo pelo qual um sistema verifica se um usuário é
realmente quem ele diz ser. Sem uma autenticação eficiente e segura, informações
sensíveis e dados críticos podem ser expostos, resultando em sérios danos
financeiros, perda de confiança e até mesmo questões legais. Neste contexto,
utilizar o Unit Authenticator é essencial para garantir a integridade,
confidencialidade, disponibilidade das informações e a proteção dos usuários e da
organização.
Estrutura da Atividade
1. Modelagem do Sistema
   ● O sistema armazenará informações de usuários, onde cada usuário terá um
   nome (chave) e uma senha (valor).
   ● O aluno deve implementar uma tabela hash para armazenar pares
   chave-valor, onde a chave será o nome do usuário e o valor será a senha.
2. Funcionalidades do Sistema
   ● Cadastro de Usuário: Inserir novos usuários e suas respectivas senhas na
   tabela hash.
   ● Autenticação: Permitir que o sistema verifique se o nome do usuário existe e
   se a senha fornecida corresponde à armazenada.
   ● Remoção de Usuário: Possibilidade de remover um usuário (e sua senha) da
   tabela hash.
   ● Verificação de Existência de Usuário: Verificar se um usuário está registrado
   no sistema.
3. Tratamento de colisões
   ● A atividade deve incluir o tratamento de colisões utilizando o método de
   encadeamento, onde várias entradas podem ser armazenadas no mesmo
   índice usando uma lista ligada.
4. Layout do sistema
   ● O sistema deve exibir inicialmente um menu com as opções para o usuário
   escolher uma determinada ação:
1. Inserção
2. Remoção
3. Busca
4. Login
5. Sair
   Entrega
1. Código fonte completo (Compactado).
2. Testes realizados, demonstrando o funcionamento do sistema.
3. Documentação explicando a implementação, no formato PDF.
   Organização (Classroom)
   Esta atividade deve ser realizada em grupo, com no máximo três
   participantes, utilizando a linguagem de programação JAVA. A documentação deve
   conter os nomes de todos os participantes do grupo. Por fim, apenas um membro da
   equipe deve enviar a atividade.
   Importante: É fundamental que os códigos sejam distintos para garantir a
   originalidade a fim de certificar a obtenção do conhecimento do produto e evitar
   qualquer tipo de plágio ou confusão durante a avaliação. Para o devido
   reconhecimento do esforço de cada um, verifiquem cuidadosamente se os códigos
   apresentados são únicos e não duplicados.
